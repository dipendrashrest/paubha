## Usage

```tsx
import { ProgressStep, ProgressSteps } from "@/components/ui/progress-steps";

<ProgressSteps variant="horizontal">
  <ProgressStep status="complete" label="Account" />
  <ProgressStep status="current" label="Profile" />
  <ProgressStep status="upcoming" label="Done" />
</ProgressSteps>
```

## Props

### ProgressSteps

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"horizontal" \| "vertical" \| "numbered" \| "description"` | from `orientation` |
| `orientation` | `"horizontal" \| "vertical"` (shorthand for `numbered` / `vertical`) | `"horizontal"` |

### ProgressStep

| Prop | Type | Default |
| --- | --- | --- |
| `status` | `"complete" \| "current" \| "upcoming"` | required |
| `label` | `ReactNode` | required |
| `description` | `ReactNode` (vertical, numbered, description) | none |
| `stepNumber` | `number` (numbered) | index + 1 |
