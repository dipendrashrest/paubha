Application patterns are copy-paste registry pieces built from the base kit. Same tokens, glow-focus, and Lucide icons, just larger compositions.

Browse any pattern in the sidebar, or install with:

```bash
npx paubha@latest add pricing-card
```

## Marketing

Announcement bar, logo cloud, marketing hero, testimonial, newsletter, site footer, pricing card, FAQ, feature list, CLI snippet, icon list, blog card, team card, cookie banner, auth card, and inline CTA.

## App chrome & data

Page header, section header, card header, app nav, empty state, filter, file upload, progress steps, metric, chart, calendar, date picker, search field, user menu, confirm dialog, settings row, comment, data toolbar, and activity feed.
