## Usage

```tsx
import { CliSnippet } from "@/components/ui/cli-snippet";

<CliSnippet
  label="Quick start"
  command="npx paubha@latest add button"
  description="Tokens, focus rings, and a11y, already baked in."
  showCopy
/>
```

`showCopy` adds a copy button (`aria-label="Copy command"`, glow-focus ring, announces "Copied"). Off by default.
