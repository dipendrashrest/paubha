## Usage

```tsx
import {
  Modal,
  ModalBody,
  ModalClose,
  ModalContent,
  ModalDescription,
  ModalFooter,
  ModalHeader,
  ModalTitle,
  ModalTrigger,
} from "@/components/ui/modal";

<Modal>
  <ModalTrigger asChild>
    <Button destructive>Delete item</Button>
  </ModalTrigger>
  <ModalContent>
    <ModalHeader>
      <ModalTitle>Delete item?</ModalTitle>
      <ModalClose />
    </ModalHeader>
    <ModalBody>
      <ModalDescription>This action cannot be undone.</ModalDescription>
    </ModalBody>
    <ModalFooter>
      <Button variant="secondary">Cancel</Button>
      <Button destructive>Confirm</Button>
    </ModalFooter>
  </ModalContent>
</Modal>
```

The close button sits inside `ModalHeader` as a flex sibling of the title
(`ModalTitle` is `flex-1`, `ModalClose` is `shrink-0`). That's what the real
spec shows, not the more common absolutely-positioned-corner-X pattern. The
overlay backdrop is `bg-bg-overlay` (black at 60% in light mode, 70% in dark)
and sits on the `--z-overlay` layer, with the panel above it on `--z-modal`.
Both fade in over `duration/normal` (200ms) with ease-out; under
`prefers-reduced-motion` they appear instantly.

Pick the smallest size that comfortably fits the task: `sm`, `md` (default),
or `lg`.

## Accessibility

<A11yCallout>
  <ul>
    <li>
      <strong>Role.</strong> <code>role=&quot;dialog&quot;</code> with{" "}
      <code>aria-modal=&quot;true&quot;</code>, set explicitly on{" "}
      <code>ModalContent</code> rather than left to Radix's default, since the
      installed Radix version doesn't set it automatically (verified directly by
      inspecting the rendered DOM, not assumed).
    </li>
    <li>
      <strong>Labelling.</strong> <code>aria-labelledby</code> points at{" "}
      <code>ModalTitle</code>, <code>aria-describedby</code> at{" "}
      <code>ModalDescription</code>, wired automatically by Radix.
    </li>
    <li>
      <strong>Focus.</strong> Moves inside on open; Tab and Shift+Tab stay
      within the modal. Background content is inert while it's open.
    </li>
    <li>
      <strong>Dismiss.</strong> Escape closes it and returns focus to the
      trigger, as does clicking <code>ModalClose</code> or the overlay. The
      icon-only close control is labelled &quot;Close&quot;.
    </li>
    <li>
      <strong>Motion.</strong> 200ms ease-out fade on open; instant when the
      user prefers reduced motion.
    </li>
  </ul>
</A11yCallout>
