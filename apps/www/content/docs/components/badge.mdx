## Usage

```tsx

<Badge variant="success">Active</Badge>
<Badge dismissible dismissLabel="Remove Frontend tag" onDismiss={() => remove(tag)}>
  Frontend
</Badge>
```

## Accessibility

<A11yCallout>
  <ul>
    <li>
      <strong>Root element.</strong> A plain <code>&lt;span&gt;</code>: static
      badges are ordinary text. Pass <code>role=&quot;status&quot;</code> only
      when the badge announces a meaningful live update.
    </li>
    <li>
      <strong>Icon-only.</strong> Renders <code>role=&quot;img&quot;</code>;
      always give it an <code>aria-label</code>.
    </li>
    <li>
      <strong>Dismiss button.</strong> Native <code>&lt;button&gt;</code>: Tab to
      focus, Enter/Space activates, <code>glow-focus</code> ring. Name each
      action specifically via <code>dismissLabel</code> (e.g. &quot;Remove
      Design category&quot;).
    </li>
    <li>
      <strong>Dot, icon, and avatar slots.</strong> Decorative,{" "}
      <code>aria-hidden</code>. State the status in visible text; never rely on
      color alone.
    </li>
  </ul>
</A11yCallout>
