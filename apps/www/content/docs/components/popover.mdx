## Usage

```tsx
import {
  Popover,
  PopoverContent,
  PopoverDescription,
  PopoverTitle,
  PopoverTrigger,
} from "@/components/ui/popover";

<Popover>
  <PopoverTrigger asChild>
    <Button variant="secondary">Open popover</Button>
  </PopoverTrigger>
  <PopoverContent>
    <PopoverTitle>Popover Title</PopoverTitle>
    <PopoverDescription>Contextual content goes here.</PopoverDescription>
  </PopoverContent>
</Popover>
```

## Accessibility

<A11yCallout>
  <ul>
    <li>
      <strong>Role.</strong> Content has an implicit{" "}
      <code>role=&quot;dialog&quot;</code>; the trigger gets{" "}
      <code>aria-haspopup=&quot;dialog&quot;</code> and{" "}
      <code>aria-expanded</code> automatically.
    </li>
    <li>
      <strong>Focus.</strong> Focus moves into the popover on open and returns
      to the trigger on close. The popover is non-modal by default; pass{" "}
      <code>modal</code> to <code>Popover</code> to trap Tab inside it. When
      the panel itself holds keyboard focus it shows a 2px focus-ring border.
    </li>
    <li>
      <strong>Keyboard.</strong> Escape or a click outside closes the popover.
    </li>
  </ul>
</A11yCallout>
