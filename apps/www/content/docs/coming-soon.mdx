New updates are coming soon. We ship the catalog in public — more application patterns, Figma file docs, and icon guidance are next. This page is the place to check what is still in progress.

## What is next

- **Application patterns** — more high-level compositions built from the base components (date pickers, calendars, dashboards, and related layouts)
- **Figma files** — how the design system maps to the registry
- **Icons** — the Lucide set used across components and the docs site
- **Grid** — layout tokens from Foundations / Grid Layouts

## Already shipped

Base components, foundations, the CLI, and the first application pattern (Activity Feed) are live. See the [changelog](/docs/changelog) for what landed and when.

Nothing listed above is a spec yet. Treat published component pages as the source of truth until these pages fill in.
